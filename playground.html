Demonstração funcional da API pública exportada por ./dist/gistdb.min.js (GistDB e Logger). Cada botão abaixo chama diretamente o módulo importado — nada aqui reimplementa ou resume a lógica interna.

0 / 11 endpoints exercitados
Antes de usar: rode o build do projeto para gerar ./dist/gistdb.min.js ao lado deste arquivo, e tenha um GitHub token com escopo gist em mãos. O token só é usado localmente, no navegador, para chamar a API do GitHub — esta página não o envia a nenhum outro lugar. Se abrir o arquivo com file://, o import de módulo ES pode ser bloqueado; sirva a pasta com um servidor estático simples (ex.: npx serve).

01 · Inicialização GistDB.create()

Único ponto de entrada público da classe. Cria o transporte, o cache local, o resolvedor de conflitos e, se necessário, um gist novo.

02 · CRUD get · set · delete · list

Opera diretamente sobre a instância retornada por GistDB.create().

03.5 · Dispositivos db.deviceId · db.devices.list()

Identifica este dispositivo e permite listar todos os aparelhos que já sincronizaram com este Gist.

03 · Sincronização sync · getLastSyncAt

sync() limpa o cache local e esvazia a fila de escrita pendente do transporte.

04 · Observação watch()

Registra um callback e inicia polling na collection informada; watch() retorna a própria função de unwatch.

05 · Encerramento destroy()

Limpa timers de polling, observadores e o token guardado no KeyVault.

06 · Cenários de erro GistDBError

Dispara intencionalmente os caminhos de erro reais da classe, sem precisar de instância válida.
